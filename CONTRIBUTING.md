# Contributing

Use Rust 1.78+, Node 20+, and pnpm 9.15. Run the commands in `AGENTS.md`. Add typed,
deterministic tests and update contracts with fixtures. Keep runtime behavior in
Rust and ergonomic interfaces in TypeScript. Do not vendor `@knolo/core`, commit
build output, introduce networked unit tests, or broaden pack authority. Changes
need review from CODEOWNERS; security reports follow `SECURITY.md`.
